{# ---------------------------------------------------------------- #} {% elif tab == 'llm' %}
Reformatage des menus via LLM

Active un appel à l'API MiniMax (compatible OpenAI) pour reformater chaque menu So-Happy en une liste courte de 5 lignes adaptée à un agenda : 

Entrée : choix 1 / choix 2
Plat : choix 1 / choix 2
Garnitures : choix 1 / choix 2
Laitage : choix 1 / choix 2
Dessert :

Aucun allergène ni flag (végé / bio / local / fait maison) n'est affiché. Si le LLM est indisponible ou si la clé manque, un formatage déterministe local (même structure, mais sans nettoyage marketing) prend le relais.

{# ---------------------------------------------------------------- #} {% elif tab == 'mqtt' %}
Home Assistant (MQTT)

Publication des menus vers Home Assistant via MQTT broker (EMQX addon HAOS typique). Active le Home Assistant MQTT integration avec Discovery sur HA — les sensors se créent automatiquement au 1er sync.

Trois entités HA sont créées par enfant : sensor.ha_menu_enfant_menu_today (menu du jour), sensor.ha_menu_enfant_menu_tomorrow (menu de demain — idéal pour une notif push le soir), et calendar.ha_menu_enfant (calendrier complet).
